# Example session

`group-nonsimplicity/` is a real, completed tutoring session — *Proving
non-simplicity via coset actions*, probe → plan → seven teaching steps —
kept here so you can see what the tutor produces before running it.
Open `session.md` in Obsidian (or any Markdown viewer with Mermaid
support) for the rendered view; `state.json` is the machine state either
frontend can resume from.

Your own sessions land in `sessions/`, which is gitignored: they are
yours, local, and never shared unless you choose to submit an experience
report.
